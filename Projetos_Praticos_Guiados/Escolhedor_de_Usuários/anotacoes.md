**HTML**

# onclick
        `--->> o que deve acontecer quando clicar.

# accept=" "
        `--->> essa característica, quando colocada, sinaliza que ali só será aceito o que foi especificado.
                        Exp.:
                                <input type="file" accept="image/*">
                                                `--->> diz que esse input receberá arquivos (file) mas só aceitará imagens (image) de todos os tipos (/*).

# hidden
        `--->> signfica "sumido" ou "oculto", ou seja, oculta algo.
                        Exp.:
                              <input type="file" accept="image/*" hidden>
                                                `--->> diz que esse input ficará oculto.

# onchange
        `--->> significa mudança. Vai pegar a ação inicial e mudar para outra.
                        Exp.: 
                                <input type="file" accept="image/*" hidden onchance="lerFoto(this)">
                                                `---> diz que esse input receberá uma foto, e ele mudará (onchange), e aplicará essa foto (this) na função "lerFoto".
                                        OBS.: o "this" é uma ferramenta do Javascript que sinaliza que será pego TUDO o que está dentro do alvo, que no caso acima, tudo que está dentro do input.
